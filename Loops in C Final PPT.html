1. What is a loop?

➜Definition: A loop repeats a block of code continuously while its condition remains true.

➜Why we need it: Writing repetitive code lines is inefficient. A loop automates hundreds of iterations in 2–3 lines.

➜Every loop has 3 parts: Initialization (start) · Condition check (continue?) · Increment/Decrement (step forward).

➜Real uses: Multiplication tables, interactive menus, reading array inputs, and game loops.

WITHOUT A LOOP
printf("Hello\n");
printf("Hello\n");
printf("Hello\n");// ...repeat 100 times
WITH A LOOP
for (int i = 1; i <= 100; i++) {
    printf("Hello\n");
}

2. Types of loops in C

for loop

Best when the total number of iterations is known. Entry-controlled: condition is checked before each iteration.

while loop

Best when iterations depend on a dynamic condition. Entry-controlled: may execute 0 times if condition is initially false.

do-while loop

Executes the body first before checking the condition. Exit-controlled: always completes at least 1 iteration.

➜ Two control statements adjust loop flow: break (terminates loop instantly) and continue (skips directly to next iteration).

3. The for loop

➜When to use: Ideal when total iteration count is predetermined.

➜Behaviour: Entry-controlled — evaluates condition before executing the loop body.

SYNTAX
for (initialization; condition; increment/decrement) {
    // body: code to repeat
}

int a = 1➜Initialization executes once at start.

a <= 5➜Condition checked before every iteration; false stops the loop.

printf()➜Body executes when condition is true.

a++➜Increment/Decrement updates counter after body execution.

EXAMPLE: PRINT 1 TO 5
#include <stdio.h>

int main() {
    for (int a = 1; a <= 5; a++) {
        printf("%d ", a);
    }
    return 0;
}
OUTPUT
1 2 3 4 5

4. The while loop

➜When to use: Use when total iteration count is unknown and depends on dynamic conditions.

➜Behaviour: Entry-controlled — if initial condition is false, loop body runs 0 times.

SYNTAX
initialization;
while (condition) {
    // body statements
    increment/decrement;
}

➜Initialize loop control variables prior to `while`.

➜Condition checked before each iteration.

➜Increment / Decrement step must be inside body to avoid infinite execution.

EXAMPLE: COUNTDOWN
#include <stdio.h>

int main() {
    int n = 5;
    while (n >= 1) {
        printf("%d ", n);
        n--;
    }
    printf("Go!\n");
    return 0;
}
OUTPUT
5 4 3 2 1 Go!

5. The do-while loop

➜When to use: Use when the code block must execute at least once (e.g. interactive menu prompts).

➜Behaviour: Exit-controlled — body executes first, condition evaluates afterward.

SYNTAX
initialization;
do {
    // body
    increment/decrement;
} while (condition);

➜Body executes first: minimum 1 iteration guaranteed.

➜Condition checked at the end of every round.

➜Trailing Semicolon: required after `while(condition);`

EXAMPLE: CONDITION IS FALSE AT START
#include <stdio.h>

int main() {
    int b = 10;
    do {
        printf("%d\n", b);
        b++;
    } while (b < 5);
    return 0;
}
OUTPUT
10

7. Nested Loops in C

➜Definition: A nested loop is simply a loop inside another loop body.

➜How it works: For every single iteration of the outer loop, the inner loop runs completely from start to finish.

➜Common Uses: Printing 2D patterns (stars, grids), working with matrices, and multi-dimensional arrays.

NESTED FOR LOOP EXAMPLE
#include <stdio.h>

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 2; j++) {
            printf("* ");
        }
        printf("\n");
    }
    return 0;
}
OUTPUT
* * 
* * 
* *
NESTED WHILE LOOP EXAMPLE
#include <stdio.h>

int main() {
    int i = 1;
    while (i <= 2) {
        int j = 1;
        while (j <= 3) {
            printf("%d ", j);
            j++;
        }
        printf("\n");
        i++;
    }
    return 0;
}
OUTPUT
1 2 3 
1 2 3

8. Avoid infinite loops: check before you run

✔Initialize loop control variables before starting execution.

✔Ensure the termination condition eventually evaluates to false.

✔Include an Increment/Decrement step inside the loop body.

✔Use relational operator == for comparison, not assignment operator =.

⚠Program trapped in an infinite loop? Press Ctrl + C in console to terminate.

BUG: INFINITE LOOP (MISSING INCREMENT)
#include <stdio.h>

int main() {
    int i = 1;
    while (i <= 5) {
        printf("%d ", i);
        // i++ is missing! i remains 1 forever.
    }
    return 0;
}
FIXED PROGRAM
#include <stdio.h>

int main() {
    int i = 1;
    while (i <= 5) {
        printf("%d ", i);
        i++; // Counter updates; loop terminates properly
    }
    return 0;
}
BUG: ASSIGNMENT IN CONDITION
#include <stdio.h>

int main() {
    int x = 0;
    while (x = 1) { // Assigns 1 (always non-zero / true)
        printf("Infinite...\n");
    }
    return 0;
}

9. The break statement

➜Loop Control Statement: break terminates execution of the loop immediately and jumps out.

SYNTAX
break;

➜Flow: Loop executes → break statement encountered → transfers control to statement right after loop.

➜Use case: Early exit, such as terminating a search once a match is found.

EXAMPLE: STOP AT 5
#include <stdio.h>

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 5)
            break;
        printf("%d ", i);
    }
    return 0;
}
OUTPUT
1 2 3 4

10. The continue statement

➜Loop Control Statement: continue skips remaining code in current iteration and moves directly to the next iteration.

SYNTAX
continue;

➜Flow: In a `for` loop, it skips directly to the increment/decrement step.

⚠Caution in `while` loops: Ensure counter updates occur before `continue`, otherwise an infinite loop occurs!

EXAMPLE: SKIP 3
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        if (i == 3)
            continue;
        printf("%d ", i);
    }
    return 0;
}
OUTPUT
1 2 4 5

➜ break terminates the entire loop. continue skips only the active iteration.
